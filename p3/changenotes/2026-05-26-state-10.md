# 2026-05-26 — STATE-10 Public input builder

## Bối cảnh

P3 đã có STATE-01..09 + STATE-13. Trong pipeline ZK settlement,
`ProofBundle.PublicInputs` là slice 6 phần tử (hex string) buộc batch
artifact vào proof:

```
publicInputs[0] = oldStateRoot
publicInputs[1] = newStateRoot
publicInputs[2] = depositsRoot
publicInputs[3] = withdrawalsRoot
publicInputs[4] = nullifiersRoot
publicInputs[5] = withdrawOutputsRoot
```

Hiện tại P4 prover client (`internal/prover/client.go:69-76`) đang
INLINE thứ tự này. Nếu một consumer (P2 circuit / P1 verifier on-chain
/ P4 relayer) tự re-build slice mà sai thứ tự dù chỉ một index → mọi
proof đang valid trở thành invalid (silent break).

STATE-10 đóng vai trò **single source of truth** cho thứ tự public
input: một builder P3 owned, một const `PublicInputIdx*` cho mọi
consumer reference. P4 prover client / P1 verifier / P2 circuit có thể
refactor sang dùng builder này khi tiện, không phải gấp.

### Quyết định thiết kế quan trọng

1. **Builder pattern thay vì pure function thuần** — giữ symmetry với
   `SettlementUpdateBuilder` / `WitnessBuilder` / `PublicInputBuilder`.
   Đồng thời `BuildPublicInputs(upd, com)` helper được expose cho
   caller stateless (script gen vector, test).
2. **Sentinel riêng `ErrInvalidPublicInputs`** — không reuse
   `ErrInvalidSettlementInputs` để consumer (P4/P1/P2) phân biệt rõ
   "settlement sai" vs "binding public input sai".
3. **Defense-in-depth validation** — STATE-08 đã reject empty/no-op
   batch, nhưng caller có thể bypass builder và đẩy SettlementUpdate
   giả mạo vào hàm này. Re-validate tại STATE-10:
   - 2 state root + 4 commitment root đều hex-prefixed, non-empty.
   - `oldStateRoot != newStateRoot` (no-op batch reject).
4. **No hash transform** — chỉ echo verbatim hex string. P1 verifier
   on-chain cũng đọc raw hex để hash → verify. Khi ZK-02 đổi sang
   field element representation (Poseidon/MiMC), bump
   `PublicInputCount` hoặc add layer wrapping, KHÔNG silent transform.
5. **Defensive copy ở `PublicInputLabels()`** — caller có thể mutate
   slice trả về, không ảnh hưởng global state. Test
   `TestPublicInputs_Labels` cover invariant này.
6. **KHÔNG modify P4 prover client (`internal/prover/client.go`)** —
   STATE-10 đặt nền cho refactor đó, nhưng việc refactor là task P4
   (out-of-scope STATE-10). Test
   `TestPublicInputs_MatchProverClientOrder` đảm bảo nếu P4 refactor
   thì thứ tự không drift.
