### Quyết định thiết kế quan trọng

1. **MANIFEST.json là source-of-truth, không phải README.** Manifest machine-readable + chứa SHA-256 → bất kỳ edit nào phải đi qua generator. README chỉ là human guide; xoá README không phá determinism (`VerifyManifest` skip README.md case-insensitive).

2. **SHA-256 placeholder, không phải Poseidon/MiMC.** Khớp đúng hash function MVP đang dùng cho commitment roots (`internal/batch/commitments.go`). Khi ZK-02 chốt circuit hash, bump `vectorVersion` v0 → v1 và đồng thời bump `ExpectedVectorVersion`. Test `TestManifest_VersionPinned` catch trường hợp chỉ bump 1 bên.

3. **FindRepoRoot dùng `runtime.Caller(0)` thay vì `os.Getwd()`.** Test invocation có thể đổi cwd (`go test ./tests/...` chạy với cwd = `tests/`). Caller(0) trỏ đúng vào source file `manifest.go` → walk up tìm `go.mod` là chỉ dấu ổn định bất kể caller.

4. **VerifyManifest detect 3 dạng drift đồng thời**:
   - File trong manifest mà không tồn tại trên đĩa.
   - File trên đĩa SHA mismatch với manifest entry.
   - File orphan trên đĩa (không có entry manifest).
   
   Bypass: `MANIFEST.json` chính nó, `README.md` (case-insensitive), file hidden bắt đầu `.`.

5. **Hai cấp invariant check**:
   - **Cấp 1** (`VerifyManifest`): byte-level SHA-256. Bắt edit tay JSON.
   - **Cấp 2** (`SanityCheck`): semantic relationship giữa files (rootB chung giữa state_after_deposit + settlementUpdate; nullifier vector match settlementUpdate; v.v.). Bắt generator bug ở mức ý nghĩa mà cấp 1 không thấy.

6. **Static "alice_secret" giữ nguyên**, KHÔNG đổi sang "mock-user-secret". Lý do:
   - STATE-06 đã lock nullifier const `0x1a1fdf4c…22f7 = H(domain | "alice_secret" | "1")` trong `internal/state/nullifier_test.go::TestNullifierFor_CanonicalAliceVector`. Đổi sẽ phá test này.
   - Runtime fallback `"mock-user-secret"` chỉ áp dụng khi P4 không truyền `AccountSecrets` (HTTP API request). Static folder là canonical baseline, runtime fallback là MVP hack.
   - README.md + `TestAlice_StaticVsRuntimeSecret` document rõ distinction này.

7. **`gen_state_vectors` đổi từ `write(name, v)` (package-level) sang `w.write(name, v, fileMeta)` (writer method)** — bắt buộc khai báo `stateTask` + `schema` cho từng file. File không metadata `die()` ngay → không cách nào sneak file orphan vào folder.
